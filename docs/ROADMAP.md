# Halo: Development Roadmap

This roadmap defines the six architectural and product phases to build Halo from prototype to a production-grade, offline-first AI wealth and tax engine for India.

## Roadmap Overview
- **Stage 0: Environment, Scaffolding, Governance & Audit (Current)**
- **Phase 1: Deterministic Tax & Rules Engine Foundation** (`docs/phases/phase-1-foundation.md`)
- **Phase 2: Local Document Ingestion & FIFO Lot Engine** (`docs/phases/phase-2-ingestion.md`)
- **Phase 3: Deep Financial Intelligence & Tool Suite** (`docs/phases/phase-3-intelligence.md`)
- **Phase 4: Design Transformation & Generative UI** (`docs/phases/phase-4-design.md`)
- **Phase 5: Signature Features & Air-Gapped Delighters** (`docs/phases/phase-5-signature.md`)
- **Phase 6: Desktop Packaging, Multi-Profile & Productization** (`docs/phases/phase-6-productize.md`)

Each phase follows the strict workflow:
1. Trigger `/phase-N` workflow or review `docs/phases/phase-N-*.md`.
2. Generate an **Implementation Plan** artifact.
3. Wait for user approval before modifying code.
4. Implement in small, verifiable commits with full test coverage.
5. Update `docs/PROGRESS.md`.
