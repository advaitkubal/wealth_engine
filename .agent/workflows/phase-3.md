# Workflow: Phase 3

When triggered:
1. Read the specification file: `docs/phases/phase-3-*.md`.
2. Produce an Implementation Plan artifact (files, data models, endpoints, test plan, risks, open tax-law questions).
3. STOP and wait for user approval before modifying code.
4. Implement in small, verifiable commits with full test coverage.
5. Run full test suite and paste real output.
6. Update `docs/PROGRESS.md`.
7. Stop and wait for user review.
